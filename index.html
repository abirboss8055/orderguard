Free & Open-Source WordPress Plugin

OrderGuard

Lightweight WooCommerce protection against duplicate and fake orders. Locks customer IP and device temporarily until an admin updates the order status.

Download orderguard.zip (Latest) View on GitHub

WordPress 6.0+ · WooCommerce 7.0+ · HPOS Compatible · Single PHP File

Universal Checkout

Works across Classic WooCommerce Checkout, WooCommerce Block Checkout (Store API), and CartFlows funnels.

Smart Auto-Unlock

Locks IP and browser device for your chosen duration, and unlocks instantly when an admin changes status from Processing.

WhatsApp Support CTA

Displays a clean lock notice with your custom message and a direct clickable WhatsApp button configured from wp-admin.

Quick Installation

  1. Click Download orderguard.zip above.
  2. In WordPress, go to Plugins > Add New Plugin > Upload Plugin.
  3. Upload orderguard.zip, install, and activate.
  4. Configure your WhatsApp number and lock duration under WooCommerce > OrderGuard.
